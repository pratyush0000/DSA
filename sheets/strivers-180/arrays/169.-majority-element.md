# 169. Majority Element

Given an array `nums` of size `n`, return _the majority element_.

The majority element is the element that appears more than `⌊n / 2⌋` times. You may assume that the majority element always exists in the array.

&#x20;

**Example 1:**

<pre><code><strong>Input: nums = [3,2,3]
</strong><strong>Output: 3
</strong></code></pre>

**Example 2:**

<pre><code><strong>Input: nums = [2,2,1,1,1,2,2]
</strong><strong>Output: 2
</strong></code></pre>

&#x20;

**Constraints:**

* `n == nums.length`
* `1 <= n <= 5 * 10`<sup>`4`</sup>
* `-10`<sup>`9`</sup>` ``<= nums[i] <= 10`<sup>`9`</sup>
* The input is generated such that a majority element will exist in the array.

&#x20;

**Follow-up:** Could you solve the problem in linear time and in `O(1)` space?



## Solution.

Moore's Voting Algorithm.

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        //using moore's voting algorithm
        //keep track of an elemnt count. if u see it +1 otherwise -1. if it goes negative chnange to the newest element u see. this gives u the best candidate for majority element. the algo asks u to do a 2nd pass to make sure it is >n/2 but cine the Q guarentees it we dont have to.
        int element = nums[0];
        int count = 1;

        for(int i = 1; i<nums.size(); i++){
            if(nums[i]==element){
                count++;
            }else{
                count--;
                if(count<0){
                    element=nums[i];
                    count=1;
                }
            }
        }

        return element;
    }
};
```

#### Complexity

* #### **Time Complexity (TC)**
  * #### 👉 Total = **O(n)**
* **Space Complexity (SC)**
  * #### 👉 Total = **O(1)**
