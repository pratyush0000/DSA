# 485. Max Consecutive Ones

Given a binary array `nums`, return _the maximum number of consecutive_ `1`_'s in the array_.

&#x20;

**Example 1:**

<pre><code><strong>Input: nums = [1,1,0,1,1,1]
</strong><strong>Output: 3
</strong><strong>Explanation: The first two digits or the last three digits are consecutive 1s. The maximum number of consecutive 1s is 3.
</strong></code></pre>

**Example 2:**

<pre><code><strong>Input: nums = [1,0,1,1,0,1]
</strong><strong>Output: 2
</strong></code></pre>

&#x20;

**Constraints:**

* `1 <= nums.length <= 10`<sup>`5`</sup>
* `nums[i]` is either `0` or `1`.



## Solution.

```cpp
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int count=0;
        int maxcount=0;
        for(int num: nums){
            if(num==1){
                count++;
                maxcount=max(maxcount,count);
            }else{
                count=0;
            }
        }

        return maxcount;
    }
};
```

#### Complexity

* #### **Time Complexity (TC)**
  * #### 👉 Total = **O(n)**
* **Space Complexity (SC)**
  * #### 👉 Total = **O(1)**
